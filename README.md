# CodeSync AI

> **Official Project Name**: CodeSync AI  
> **Type**: Real-Time Collaborative Cloud IDE & AI-Powered Code Editor

---

## Overview

**CodeSync AI** is a real-time collaborative cloud IDE combining a VS Code-inspired frontend (Monaco Editor, Tailwind CSS), a scalable microservices backend (Node.js, Express, Socket.IO, Redis), sandboxed code execution (Docker, BullMQ), and project-aware AI assistance with pgvector RAG.
